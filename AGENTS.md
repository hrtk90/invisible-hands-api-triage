# Repository Instructions

This is a research demonstrator for museum collections metadata.

- Do not infer migrant status from names, places, or maker fields alone.
- Separate catalogue-supported evidence, research prompts, and evidence gaps requiring archival follow-up.
- Every generated label must be traceable to visible V&A API fields.
- The tool ranks records by archival tractability, not migrant likelihood.
- Keep the app small, transparent, and reproducible.
- Run tests before reporting completion.
- Use Windows-compatible commands when running local checks.
